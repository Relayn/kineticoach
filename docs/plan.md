## 1. Цель Проекта

Создать **Telegram Mini App** для анализа техники выполнения упражнений в реальном времени через камеру. Проект демонстрирует два направления:
1. **Фитнес / Суставная гимнастика**: Анализ приседаний с определением 5 типов ошибок
2. **Йога / Сурья Намаскар**: Анализ переходов в упражнении "Кошка-Корова"

Приложение предоставляет **голосовые корректирующие подсказки** в режиме реального времени для улучшения техники выполнения.
