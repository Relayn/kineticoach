### ✨ Ключевые возможности

- **🎯 Множественные упражнения**:
  - **Фитнес**: Приседания с анализом 5 типов ошибок
  - **Йога**: Кошка-Корова с анализом переходов между позами

- **🔊 Голосовые подсказки**: Real-time TTS корректировки через OpenAI API

- **📱 Telegram Mini App**: Нативная интеграция в Telegram без установки отдельного приложения

- **⚡ Client-Side Pose Detection**: MediaPipe работает в браузере через WebAssembly + WebGL

- **🔒 Security First**: Соответствие OWASP Top 10, проверки через `bandit`, `semgrep`, `mypy`

- **🐳 Docker Ready**: One-command deployment через `docker-compose up`

- **🧪 High Test Coverage**: >90% coverage через `pytest` и `jest`
